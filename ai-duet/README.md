# AI Duet Text Free

Versión móvil de texto para alternar conversaciones entre ChatGPT y Gemini sin API de OpenAI.

## Uso

1. Escribe el tema.
2. Inicia la conversación.
3. Copia el prompt y ábrelo en ChatGPT o Gemini.
4. Comparte, pega o sube la respuesta en AI Duet.
5. AI Duet conserva el historial y prepara el siguiente turno.

## Android

Instalada como PWA desde GitHub Pages, AI Duet declara un Web Share Target para recibir texto compartido desde otras apps.
