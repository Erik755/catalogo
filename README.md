# Catálogo — portfolio & demos

Personal portfolio site of Erik Sanchez on GitHub Pages, with small front-end demos and a public privacy-policy page.

**Live:** https://erik755.github.io/catalogo/

| Path | Content |
|---|---|
| `/` | Portfolio / contact page (HTML, CSS, vanilla JS) |
| `/demos/landing`, `/demos/blog`, `/demos/ecommerce` | Front-end demo pages (landing, blog, e-commerce catalog) |
| `/ai-duet/` | *AI Duet* — installable PWA demo |
| `/p/` | Privacy policy for the *Reporte de Servicio* Android app (linked from Google Play — do not move) |

Plain HTML/CSS/JavaScript, no build step. Run locally with `python3 -m http.server`.
